# 既知の制約

## 並走中の Electron 版の追記は、再起動まで取り込まない
`history.jsonl` を読むのは起動時だけ。Electron 版を併用している間に追記された履歴は、Swift 版を再起動するまで検索・送りに出ない。
Electron 版を外せば起きない。併用が長引くなら、パネルを開くときにファイルサイズを確かめて、増えていれば末尾 5,000 行を読み直す。

## 1MB を超える下書きは保存されない
`DraftStore.save` は 1,000,000 バイトを超えると保存せず `false` を返す。呼び出し側は結果を見ないので、保存済みの古い下書きが残る。
Electron 版も同じ上限で、実際の入力(中央値 11 文字・95 パーセンタイル 43 文字)では起きない。

## 旧ビルドが作ったデバッグログは 0644 のまま
`PROMPT_LINE_LOG` で指定したログの新規作成は 0600 だが、既存のログの権限は変えない。以前のビルドで作ったログが残っていれば、`chmod 600` するか削除する。
